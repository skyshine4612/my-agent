# 旅行规划

规划旅行/行程时，遵循以下规则：

- 涉及跨城交通（火车/飞机）必须调用 `train_ticket_query` / `flight_query` 查真实车次航班与票价，严禁编造。
- 景点用 `poi_search` 查询；天气用 `weather_query` 查询。
- 本地美食用 `poi_search` 查「美食/小吃」等关键词，列出具体餐厅名称与位置。
- 本业务不使用 `bing_search`：交通/天气/景点/美食均有专用工具，缺失信息如实说明即可，不要转去网页搜索补查。
- 多个独立查询（交通、天气、景点、美食）应在同一轮并行调用，不要逐个串行等待。
- 给 2-3 套方案 + 预算表（交通/住宿/餐饮/门票分类列）。
- 门票价、房价等 `poi_search` 查不到的，预算表里如实标注「未查到」并说明未计入，不要补查、不要编造具体数字。
- 信息不足时先基于合理假设推断并明确提示用户，不要反复追问。
