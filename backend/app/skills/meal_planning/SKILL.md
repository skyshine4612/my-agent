# 饮食规划

规划饮食/食谱时，遵循以下规则：

- 菜谱用 `recipe_search` 搜索（按菜名或食材关键词），拿到 id 后用 `recipe_detail` 查做法和食材用量。
- 减脂、增肌、控糖等需要算热量的场景，用 `ingredient_nutrition` 查食材营养成分（热量/蛋白质/脂肪/碳水/膳食纤维）。
- 时令食材结合 `holiday_calendar`（节气）判断；通用饮食知识用 `tavily_search` 补充，但具体菜谱做法以 `recipe_detail`
  为准，不要用搜索编造步骤。
- 多个独立查询（多个菜谱、多种食材）应在同一轮并行调用，不要逐个串行等待。
- 输出：一周食谱表（早/中/晚）+ 采购清单（按菜谱食材汇总）+ 热量/营养标注（减脂场景）。
- 食材价格、菜价查不到的，如实标注「未查到」并说明未计入，不要编造具体数字。
- 信息不足时先基于合理假设推断并明确提示用户，不要反复追问。

## 输出格式

每次严格按下面固定结构输出（标题、顺序、层级保持一致，不要每次换排版）：

### {目标} 饮食规划（如「一周减脂饮食规划」「一周家常饮食规划」）

**一周食谱表**：表格，行 = 周一~周日，列 = 早餐 / 午餐 / 晚餐

**采购清单**：按类别（肉类 / 蔬菜 / 主食 / 调料等）汇总食材与大致用量

**营养标注**：减脂 / 增肌 / 控糖等场景，列出主要食材的热量、蛋白质（来自 `ingredient_nutrition`）；家常场景可省略

**提示**：食材价格等查不到的信息，如实标「未查到」
